What it fills in, and what to check

✓ Fills in

  • Names, state, ZIP, dates of birth and ages
  • Who is on the quote, and the kids
  • Income, medications and conditions they told you
  • What they pay today, if they said
  • A brief at the top of the intake with every open item

✗ Leaves blank on purpose

  • Anything nobody asked, like tobacco. Blank means “not asked”, never “no”
  • A medication it can’t spell. It flags it in the brief instead
  • Phone, email and street address. Calls rarely have them

Before you quote from it: read the brief at the top of the intake, confirm every medication and condition with the client, and check the state. A number Claude worked out itself is marked MODELLED. Never read a modelled number to a client as a quote.

🔴 Your details never go in the file

A client file holds the client, never the agent: no agency, phone, email, NPN, bio, booking link or Direction Rx code. MyPopPro takes them out when it saves, and fills in yours when you open a file. So a file built by anyone opens as you.

For that to work, save your own Setup once: MyPopPro → Setup → Save my Setup.

Keeping it current

When MyPopPro adds a field, the prompt is updated here. The version you have is stamped at the top of the prompt. The first time you build a file in a conversation, Claude checks this page’s version and tells you in one line if yours is older. Then come back and copy it again.

An older prompt still works. It builds a file that loads fine, but it may miss the newest fields. There’s nothing to install or update: copying again is the update.

On a Mac with Claude Code

There’s also a version for Claude Code. It installs as a skill, so “build POP Pro” works in any session, and it comes with a checker that loads the file into MyPopPro before you do and fails it if anything is wrong. Ask Jesse for the build-poppro kit.

Privacy

  • Transcripts carry dates of birth and health details, and sometimes Social Security or bank numbers.
  • Never paste a Social Security number. If one is in the transcript, Claude drops it and tells you. The file never contains one, or a bank, routing or driver’s licence number.
  • Use your own Claude account, and delete the conversation when you’re done if you don’t need it again.
